# Signal Desk

A fictional media-response operations dashboard for Meridian Signal Group. See [BRIEF.md](BRIEF.md) for the specification and [docs/SESSION.md](docs/SESSION.md) for progress and continuation notes.

Vue 3, TypeScript, Vite, Vuetify and Apache ECharts. All organizations, coverage and people are invented. Browser-local actions do not send notifications or modify shared team state.

Implementation and publication in progress.
